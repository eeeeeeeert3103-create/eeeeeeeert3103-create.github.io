# ЧИО ЧИО Владимир — демо без сервера

Клиент и мастер в одном статическом сайте. Данные живут в браузере (localStorage),
сервер не нужен: страницу можно открыть на любом хостинге статики.

- `client.html` — кабинет клиента: салон, услуга, фото, анкета, разбор, запись, талон, отзыв.
- `master.html` — рабочее место: очередь заявок, живая очередь, разбор, оплата, отчёты.
- `data.js` — демо-данные сети (салоны, прайс, мастера, заявки).
- `mock-api.js` — API поверх localStorage, повторяет серверные маршруты.
- `analysis.js` — правила разбора стрижки.
