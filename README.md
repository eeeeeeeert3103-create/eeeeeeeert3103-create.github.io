# ЧИО ЧИО Владимир — демо без сервера

Клиент и мастер в одном статическом сайте. Данные живут в браузере, сервер не нужен.

- `client.html` — кабинет клиента: салон, услуга, фото, анкета, разбор, слоты, талон, отзыв.
- `master.html` — рабочее место: очередь заявок, живая очередь, разбор, оплата, отчёты.
- `data.js` — демо-данные сети (салоны, прайс, мастера, заявки, часы работы).
- `mock-api.js` — API поверх localStorage, повторяет серверные маршруты.
- `analysis.js` — правила разбора стрижки.
- `face-ai.js` и `vision/` — определение формы лица в браузере (MediaPipe), без ключей и сервера.
- `ai-settings.js` — кнопка «ИИ»: можно подключить внешнюю модель по своему ключу.

Форма лица считается локально во вкладке: модель скачивается один раз, фото никуда не отправляется.
